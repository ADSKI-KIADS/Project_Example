# Asset Sources for Public Domain Astronaut Models

The following resources provide free, public‑domain (CC0 or similarly permissive) low‑poly astronaut models that can be used in the project without attribution (though credit is appreciated). All assets should be downloaded, inspected for license compliance, and stored under `Assets/Models/`.

## 1. Poly Pizza
- URL: https://poly.pizza
- Search term: "astronaut"
- License: Mostly CC‑BY (requires attribution). Some assets may be CC0; check each model’s license page.
- Recommended model: *Low‑Poly Astronaut* (download `.fbx`).

## 2. Sketchfab (CC0 filter)
- URL: https://sketchfab.com
- Filter: Downloadable + License = CC0 (Public Domain)
- Search term: "low poly astronaut"
- Example: *Astronaut CC0* – `.glb` format, rigged.

## 3. Kenney.nl Assets
- URL: https://kenney.nl/assets
- Space kit (CC0) includes astronaut‑style sprites and simple 3‑D shapes that can be adapted.
- No dedicated astronaut model, but useful for UI and environment.

## 4. Free3D / CGTrader (check licenses)
- URL: https://free3d.com, https://cgtrader.com
- Look for “public domain” or “CC0” tags.
- Example: *Low‑Poly Astronaut* (may require attribution).

## 5. BlendKit (rigged models)
- URL: https://blendkit.com
- Search for “astronaut” and filter by license.
- Many models are royalty‑free; verify CC0.

### Usage notes
- Verify each downloaded file’s license before importing into Unity.
- Store original files in `Assets/External/Raw/` and processed Unity‑ready versions in `Assets/Models/`.
- Record the exact source URL and license in `PROVENANCE.md` for each asset.
